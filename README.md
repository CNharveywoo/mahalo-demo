# mahalo-demo

一个命令行下的冒泡排序动态演示工具（中文）。

## 功能
- 在控制台动态显示冒泡排序每一步的比较与交换
- 支持输入自定义整数序列，默认示例数据为 `8 3 5 1 9 2 6`

## 要求
- Python 3.6+

## 使用方法
在项目目录下运行：

```powershell
python mahalo.py
```

按提示输入一组整数（用空格分隔），或直接回车使用示例数据。

## 可配置项
- 在源码中可通过修改 `DELAY_SECONDS` 常量调整动画延迟。
